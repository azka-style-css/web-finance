========================================================================
                      CLASS FINANCIAL MANAGEMENT - NODE.JS
========================================================================

PROJECT DESCRIPTION:
A Node.js web application for recording and managing class cash flow with 
an interactive web interface.

DIRECTORY STRUCTURE:
- index.js     : Main server file (Entry Point).
- connect.js   : Data connection setup.
- package.json : Project configuration and dependencies.
- public/      : Frontend static files (HTML, CSS, JS).

SETUP AND USAGE:
1. Open terminal in the 'keuangan_kelas' directory.
2. Run 'npm install' to install dependencies.
3. Start the application using 'node index.js'.
4. Access the application via browser at http://localhost:3000.
